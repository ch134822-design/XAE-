Como funciona o algoritmo matemático do XAE?

Cada caractere do texto é convertido em um valor alfabético. Esse valor é transformado em um vetor de três posições dentro de uma matriz de base 4. Cada posição pode assumir uma das quatro raízes fundamentais do XAE: XAE, XALON, XABI e ALONSO.
